專案概述

將老闆口述的指令自動化成結構化報告：語音轉文字後，AI Planner 拆解任務並分派給 Research Agent，每個 Agent 透過 ReAct Loop 自主搜尋、驗證、合成報告。

追蹤能力說明
①Tavily 來源追蹤
每條 query 對應的 URL + relevance score 全部記錄。報告引用了哪些來源、搜了幾輪，完整可查。score 由 Tavily 計算，分數低的來源校稿時重點審查。

②Financial Tool Calling
check_financial_need 讓 Haiku 決定呼叫哪些 yfinance 工具（Q2），fetch_financial_data 自動抓取。

每個工具輸出含 as_of（股價 / 指標）或 period_end（財報）時間戳，數字有明確日期，不是模型自行推測。
stock_price · financials · key_metrics · holders
③數字換算 Audit
raw（Haiku verbatim echo）與 zh（Python 確定性換算）並排。
912B → 9,123億、19.34B → 193.4億，可逐行核對有無差 10 倍。
防 LLM 把 billion 誤算成億
④前提 & 覆蓋度驗證
每個任務斷言與問題標 ✓ / △ / ✗。[missing] 強制報告明寫「資料不足」，禁止用空洞詞彙替代。
防 LLM 用沾邊事實填空
設計理念

Word 文件給老闆看，.log 給自己做品管。這個數字從哪來？哪個工具幾號抓的？這個前提有沒有 evidence？從根源阻止 hallucination 滲入最終報告。
